# SOT — DEFINITION OF DONE

## Project first milestone — Commercial Proof

At least one verified attributed Shopee order generated by the V3 Facebook content loop.

## Project financial milestone — FIRST REAL CASH

Shopee-related funds:
1. actually received;
2. attributable to V3 activity;
3. reconciled to commission/payout evidence;
4. recorded in Cash Truth.

## V3 loop operational DoD

- trend candidate ingestion works;
- product mapping works;
- rights/policy gate works;
- content generation/render/QA works;
- authorized Facebook publish/reconcile works;
- performance collection works;
- Shopee affiliate/commerce telemetry works;
- Cash Truth works;
- Control shows real state;
- experiment engine creates evidence-driven next actions;
- normal operation is zero-touch except defined Owner boundaries.

## Subsystem DoD standard

A subsystem is not DONE because code exists.

DONE requires:
- contract documented;
- runtime path exercised;
- failure modes classified;
- telemetry visible;
- evidence stored;
- recovery behavior known;
- no unresolved critical authority/security ambiguity.

## Scale DoD

Do not call the business scalable merely because throughput is automated.

Scale requires repeatable commercial evidence and stable operations.

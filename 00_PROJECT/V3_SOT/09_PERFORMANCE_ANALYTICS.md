# SOT — PERFORMANCE ANALYTICS

## Purpose

Measure whether attention is qualified and whether creative decisions improve the money path.

## Facebook metrics

At minimum when available:
reach/views, watch time/retention, completion, reactions, comments, shares, saves, profile/page actions, outbound clicks, followers gained.

## Commercial joins

Join performance to:
page -> post -> creative -> hook -> lane -> product -> affiliate link -> experiment -> commerce events.

## Primary diagnostic funnel

qualified views
-> outbound/affiliate clicks
-> attributed orders
-> approved commission
-> reconciled cash

## Qualified view

Define per format in runtime but exclude obvious invalid/test traffic when identifiable.

## Analysis law

Do not use a single metric as winner truth.

Examples:
- strong reach + weak clicks = content/offer bridge problem;
- strong clicks + weak orders = product/listing/intent mismatch;
- orders + weak approved commission = quality/reversal/economic problem.

## Update cadence

Collect fast enough to make useful decisions without abusing APIs or overreacting to tiny samples.

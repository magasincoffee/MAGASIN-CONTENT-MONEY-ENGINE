# SOT — FACEBOOK FANPAGE DISTRIBUTION

## Canonical V1 surface

Facebook Fanpage is the primary distribution property.

Personal profile is not the canonical Shopee Affiliate distribution surface.

## V1 page policy

Start with one primary Fanpage unless evidence proves a second page materially improves economics.

The page must have a coherent audience promise even while testing multiple content lanes.

## Page state

Required runtime fields:
- page_id / safe reference;
- owner_authorized;
- publish_capability;
- analytics_capability;
- restriction/health status;
- last_successful_publish_at;
- last_successful_metrics_sync_at.

## Publishing rules

- only authorized publishing paths;
- no spam bursts;
- no fake engagement;
- no account farming;
- no policy evasion;
- every post has a deterministic publish key;
- every side effect is reconciled to the platform post ID.

## Scaling page count

Open another page only when:
- the current page has a stable content/audience model;
- the new lane is materially incompatible with the current audience promise; or
- a controlled test predicts higher cash efficiency.

More pages is not a success metric.

## D01 gate

Fanpage must be VERIFIED, WAIT_OWNER, or BLOCKED with explicit evidence.

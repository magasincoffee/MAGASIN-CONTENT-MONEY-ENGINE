# SOT — CONTENT FACTORY

## Purpose

Turn an approved opportunity into differentiated Vietnamese creatives quickly and repeatably.

## Pipeline

opportunity
-> content brief
-> hook variants
-> script
-> shot/asset plan
-> rights-safe asset set
-> edit plan
-> render
-> captions/graphics/audio
-> QA
-> affiliate CTA/link binding
-> publish-ready package

## Required creative metadata

creative_id, lane_id, opportunity_id, product_id, experiment_id, hook_id, format, duration, script_version, asset provenance, rights_status, policy_status, render_version, CTA, target URL, QA result.

## Differentiation

Variants must test a meaningful variable:
hook, angle, structure, proof, audience problem, CTA, pacing, format, or product comparison.

Do not generate cosmetic duplicates just to increase volume.

## QA gates

- rights PASS;
- claims supported;
- Vietnamese quality;
- no broken visual/audio;
- CTA matches product;
- affiliate disclosure where required;
- no duplicate/minor-edit repost pattern;
- deterministic content hash/id.

## Throughput law

Increase output only when the experiment engine can still attribute results to meaningful hypotheses.

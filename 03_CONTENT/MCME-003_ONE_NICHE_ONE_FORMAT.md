# 2. Niche-selection rules

A niche survives SIMPLIFY only if it has:

- clear buyer problem / commercial intent;
- current Pinterest discovery evidence;
- at least one credible public affiliate merchant path;
- products that are visually understandable;
- original-content strategy that does not require reupload;
- low legal/medical/financial/regulated-claim burden;
- low production time/cost;
- clear CTA to merchant;
- repeatable content concepts;
- low Owner dependency;
- future automation fit **after** conversion proof.

Merchant-path classification:

- **VERIFIED_PUBLIC_PATH** — an official merchant page publicly confirms an affiliate program/network relevant to the niche.
- **PLAUSIBLE_BUT_ACCOUNT_REQUIRED** — the network publicly supports advertiser discovery, but actual niche merchant eligibility/terms require the real account/program view.
- **UNKNOWN** — no sufficient current public evidence.
- **REJECT** — path is incompatible or too weak for current first-cash use.

No merchant approval is assumed.

# 6. Static Pin vs simple original video Pin

## Format A — Static image Pin

**Verified platform mechanics**

Pinterest's current standard-image guidance states that a standard image can be used to generate organic impressions and recommends a vertical **2:3 aspect ratio / 1000 × 1500 px**. [S16]

Pinterest creative guidance emphasizes vertical composition, useful/actionable creative, clear product/idea presentation and a complete visual story. [S17]

**Operational characteristics for MCME**

- one original image asset;
- no voice;
- no audio rights;
- no motion editing;
- no render pipeline;
- no footage sourcing;
- can communicate a checklist, selection matrix, zone map or measurement guide;
- can include the route's outbound link independently of whether the asset moves.

**INFERENCE:** lowest production burden and fastest falsification format.

## Format B — Simple original video Pin

Pinterest supports video Pins, but the format adds:

- footage or motion design;
- timeline/editing;
- rendering/export;
- potentially music/audio rights;
- additional QA for movement/text timing;
- product demonstration expectations if the topic becomes product-specific.

No current evidence shows that this extra burden is **required** to test the first affiliate click/conversion loop.

## Format decision

**DELETE video from the first experiment.**

There is no evidence that video is necessary to answer the first-money question.

# EXPERIMENT PROTOCOL V1

## Purpose

Reach real cash evidence with the least time and capital.

## Experiment unit

```text
Market × Platform × Niche × Format × Monetization Method
```

Example:
US × YouTube Shorts × kitchen problem/solution × narrated demo × affiliate.

## Before production

Must define:
- monetization hypothesis;
- target audience;
- market/language;
- source rights strategy;
- expected CTA;
- expected conversion path;
- production cost ceiling;
- success/failure criteria.

## Default batch

10–30 pieces is a starting heuristic, not a law.

Use a smaller batch when one outcome can falsify the hypothesis.
Use a larger batch only when noise requires it.

## Evaluation

Do not ask only “did it go viral?”

Ask:
- Did we get qualified attention?
- Did intent occur?
- Did transactions occur?
- Did cash settle?
- What did one piece cost?
- What bottleneck dominates?
- Which assumption was wrong?

## Scale gate

Do not scale output merely because views rise.

Scale only when the money loop has evidence and policy/rights quality remains stable.
